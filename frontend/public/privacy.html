Privacy & analytics

Valorant AI Companion · last updated September 2026

What we collect

The app keeps a small, anonymous usage log so its operator can see which features get used and whether requests fail. An event contains:

  • an event name and tiny properties — e.g. which tab was opened, an API endpoint template like /riot/matches/{name}/{tag} (the template only, never the actual name or tag), latency, and success/failure;
  • a random anonymous visitor id and a per-session id — random UUIDs generated in your browser, tied to nothing else;
  • the page path and, once per session, the referrer's host only (e.g. discord.com, never the full URL).

Never collected: Riot IDs, names, tags, query strings, chat messages, match data, IP-based profiles, or anything from third-party trackers — there are none.

Do Not Track

If your browser sends the Do Not Track signal, analytics is fully disabled — no ids are created and no events are sent.

Where it lives

Events go to this site's own backend and are stored in a SQLite database on the operator's server. Nothing is sent to third-party analytics services, and the data is not sold or shared.

How to clear your data

What the app keeps in your browser:

  • vac:vid — anonymous visitor id (localStorage)
  • vac:last-player — the last Riot ID you searched, so the app can restore it (localStorage, stays on your device)
  • vac:recent-players — the last few Riot IDs you searched, for the quick-switch chips; one tap on "Clear recent" in the app removes it (localStorage, stays on your device)
  • vac:analysis:<player> — the last AI performance analysis you ran for a player, so a reload doesn't cost another AI call (localStorage, stays on your device)
  • vac:tilt:<player> — the last tilt report you ran for a player, same reason (localStorage, stays on your device)
  • vac:sid — session id (sessionStorage, cleared when the tab closes)

Coach chat messages are never stored — not in your browser, not on the server.

Clear them via your browser's site-data settings, or from the console: localStorage.clear(). A fresh random visitor id is only created on your next visit (unless Do Not Track is on).
